Overview

Empower@Home is a self-paced online program that helps older adults take charge of their emotional well-being, with a printed workbook and a trained coach. I redesigned the website, the workbook and coaching guide, and designed the provider dashboard with the developers.

01Accessibility review

Start with what users can’t see

axe DevToolsWAVEManual check

The audience is older adults, so the audit came first. Missing links and alt text are invisible on screen but break the experience for screen-reader users — I combined automated tools with manual checks for what tools miss.

Visual

Contrast and font size
